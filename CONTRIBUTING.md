# Contributing

Contributions are welcome for prompt hardening, adversarial fixtures, documentation, and Make blueprint compatibility.

Before opening a pull request:

1. Run `npm test`.
2. Add a fixture for every newly addressed failure mode.
3. Do not broaden repository permissions.
4. Document any new external service or data transfer.
5. Keep AI output advisory and human-reviewed.

Security changes should explain the threat, the boundary affected, and why the change does not silently increase agent authority.
